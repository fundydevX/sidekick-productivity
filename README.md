# Sidekick To-Do — product page

Single-page marketing site for the **Sidekick To-Do** Android app.

## Contents

| Path | Purpose |
| --- | --- |
| `index.html` | The whole site — inline CSS and a little vanilla JS, no build step |
| `assets/hero.jpg` | Hero artwork |
| `assets/icon.png` | App icon / logo |
| `assets/favicon.png` | Browser favicon |
| `.nojekyll` | Tells GitHub Pages to serve files verbatim (skips Jekyll) |

## Local preview

Open `index.html` directly in a browser, or serve the folder:

```powershell
python -m http.server 8080
# then open http://localhost:8080
```
